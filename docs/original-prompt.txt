And this is the version I would actually paste into Astra.

Build the first UI/architecture prototype for a browser-based multiplayer professional video editor.
Read this entire request before writing code. Do not prematurely simplify the scope. This first pass is intentionally UI-heavy.
The product can best be described as a simplified professional editor inspired by the workflow of DaVinci Resolve combined with the real-time collaboration experience of Google Docs/Figma. Do not visually clone DaVinci Resolve or use its branding/trade dress. Create an original, extremely polished modern interface while retaining the familiar workflow of a professional nonlinear video editor.
IMPORTANT: I do not want you to build the actual professional video-processing engine in this pass.
I want the near-complete UI shell, application architecture, panels, component hierarchy, fake data, interactions, state model, and visual language for the product we will ultimately build. Many controls can be mocked, but essentially every major piece of the eventual product should have somewhere to live in the UI now.
This should not look like a wireframe. It should look like a polished product.
